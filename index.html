Step 1 — Create a Firebase Project

  1. Go to console.firebase.google.com
  2. Click "Add project" → name it kk-ledger
  3. Disable Google Analytics (not needed) → Click "Create project"

Step 2 — Enable Realtime Database

  1. In the left sidebar click Build → Realtime Database
  2. Click "Create Database"
  3. Choose location: us-central1 (or any) → Next
  4. Select "Start in test mode" → Click Enable

Step 3 — Get your Database URL

After enabling, you'll see your database URL at the top. It looks like:

📲 Install KK Ledger on iPhone / iPad
1. Tap the Share button (□↑) at the bottom of Safari
2. Scroll down and tap "Add to Home Screen"

📲 Install KK Ledger as App
Chrome requires a local server to install PWA apps. Choose the easiest method below:
⚡ Method 1 — Easiest (No install needed)
1. Open Command Prompt (Win+R → type cmd)
2. Type: cd C:\Users\Dell\Downloads and press Enter
3. Type: python -m http.server 8080 and press Enter
   (If that fails, try: python3 -m http.server 8080)
4. Open Chrome → go to http://localhost:8080/KK_Trading_Ledger_Fixed_7.html
5. Click the Install icon (⊕) in Chrome's address bar
🟢 Method 2 — VS Code (if installed)
1. Open the HTML file in VS Code
2. Install the Live Server extension (by Ritwick Dey)
3. Right-click the file → "Open with Live Server"
4. Chrome opens at http://127.0.0.1:5500/...
5. Click the install icon in Chrome's address bar ⊕
ℹ Why does this happen?
Chrome blocks PWA install on file:// paths for security reasons. It only allows install from http://localhost or https:// URLs. Your data is safe — it stays in your browser's localStorage either way.
