Step 1 — Create a Firebase Project

  1. Go to console.firebase.google.com
  2. Click "Add project" → name it kk-ledger
  3. Disable Google Analytics (not needed) → Click "Create project"

Step 2 — Enable Realtime Database

  1. In the left sidebar click Build → Realtime Database
  2. Click "Create Database"
  3. Choose location: us-central1 (or any) → Next
  4. Select "Start in test mode" → Click Enable

Step 3 — Get your Database URL

After enabling, you'll see your database URL at the top. It looks like:

https://kk-ledger-default-rtdb.firebaseio.com

Copy that URL and paste it below.

Step 4 — Paste your Database URL

⚠ Do NOT include a trailing slash. The URL ends in .firebaseio.com

Step 5 — Set Database Rules (Important!)

  1. In Firebase console → Realtime Database → Rules tab
  2. Replace all rules with this:

Then click Publish. These rules block everyone except this app (via the secret key below) — much safer than open rules, which let anyone on the internet who finds your database URL read or delete everything.

Step 6 — Get Your Database Secret

  1. In Firebase console, click the ⚙ gear icon → Project settings
  2. Go to the Service accounts tab
  3. Click Database secrets (near the bottom — may say "legacy")
  4. Copy the secret shown there and paste it below

⚠ Treat this like a password — anyone with it can read/write your data. It's stored only on this device (localStorage), never in the app's source code or GitHub.

ℹ Where is my data stored?
🔥 Firebase — safest, live synced to Google's servers, works on all devices
🟡 This browser — localStorage, lost if you clear browser data
🔵 This HTML file — only contains the original startup data, NOT your new entries
🔴 If you lose the HTML file — your data is safe in Firebase. Just open any copy of the HTML file, connect to the same Firebase URL and click Sync Now.
🔄 Reset & Reload from HTML

Use this only if inside valley parties are missing. Downloads a backup first, then reloads fresh data from this HTML file.

🗓️ Start Next Fiscal Year

Moves the "current fiscal year" pointer forward. Nothing is deleted or archived — all transaction history stays exactly as-is and remains fully editable from Old Records at any time. Opening balances for every year are always computed live from the full history, never stored.

🛠️ Correct Current Fiscal Year

Use this only if the "current fiscal year" above is showing the wrong year (e.g. it got moved forward by mistake). This directly sets the pointer — it does not touch any transactions or balances, and Bill No. / Receipt No. numbering will restart from 1 for whichever year you pick.

📲 Install KK Ledger as App
Chrome requires a local server to install PWA apps. Choose the easiest method below:
⚡ Method 1 — Easiest (No install needed)
1. Open Command Prompt (Win+R → type cmd)
2. Type: cd C:\Users\Dell\Downloads and press Enter
3. Type: python -m http.server 8080 and press Enter
   (If that fails, try: python3 -m http.server 8080)
4. Open Chrome → go to http://localhost:8080/KK_Trading_Ledger_Fixed_7.html
5. Click the Install icon (⊕) in Chrome's address bar
🟢 Method 2 — VS Code (if installed)
1. Open the HTML file in VS Code
2. Install the Live Server extension (by Ritwick Dey)
3. Right-click the file → "Open with Live Server"
4. Chrome opens at http://127.0.0.1:5500/...
5. Click the install icon in Chrome's address bar ⊕
ℹ Why does this happen?
Chrome blocks PWA install on file:// paths for security reasons. It only allows install from http://localhost or https:// URLs. Your data is safe — it stays in your browser's localStorage either way.
